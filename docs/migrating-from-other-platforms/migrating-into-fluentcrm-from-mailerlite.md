# Migrating into FluentCRM from MailerLite
From your contact dashboard, click **Import**.

![click on import](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailerlite/Click-on-import-1024x492.png)

Then, choose **Import from Other Platforms** and select **MailerLite** from the list of providers.

![import from other providers](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailerlite/Import-From-Other-Providers-1024x485.png)
![select mailerlite](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailerlite/Select-MailerLite-1024x383.png)

On the next screen, you will be asked to give MailerLite API Key, you can acquire the API key by going to **MailerLite [Account -> Integrations -> Developer API](https://app.mailerlite.com/integrations/api/)**

Now Give your API keys and hit Next.

![give your api key mailerlite](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailerlite/Give-your-API-Key-MailerLite-1024x402.png)

Now, simply map all the data(lists, tags, information) you need to import in FluentCRM and click continue.

![map fields mailerlite](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailerlite/Map-Fields-MailerLite-1024x878.png)

Finally, review and Confirm!

![review and confirm](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailerlite/Review-and-Confirm-1024x253.png)

Your all contacts with all their selected properties will be imported.
