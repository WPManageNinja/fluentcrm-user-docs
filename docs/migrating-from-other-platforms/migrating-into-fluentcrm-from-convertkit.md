# Migrating into FluentCRM from Convertkit
From your contact dashboard, click **Import**.

![click on import](/migrating-from-other-platforms/migrating-into-fluentcrm-from-convertkit/Click-on-import-1024x492.png)

Then, choose **Import from Other Platforms** and select **ConvertKit** from the list of providers.

![import from other providers](/migrating-from-other-platforms/migrating-into-fluentcrm-from-convertkit/Import-From-Other-Providers-1024x485.png)
![select convertkit](/migrating-from-other-platforms/migrating-into-fluentcrm-from-convertkit/Select-ConvertKit-1024x384.png)

On the next screen, you will be asked to give ConvertKit API Key and API Secret, you can acquire the API key and secret by going to **ConvertKit [Account -> Settings -> Advanced](https://app.convertkit.com/account_settings/advanced_settings)**

Now Give your API keys and hit Next.

![give api convertkit](/migrating-from-other-platforms/migrating-into-fluentcrm-from-convertkit/Give-API-ConvertKit-1024x406.png)

Now, simply map all the data(lists, tags, information) you need to import in FluentCRM and click continue.

![map your data convertkit](/migrating-from-other-platforms/migrating-into-fluentcrm-from-convertkit/Map-Your-Data-ConvertKit-1024x843.png)

Finally, review and Confirm!

![review and confirm](/migrating-from-other-platforms/migrating-into-fluentcrm-from-convertkit/Review-and-Confirm-1024x253.png)

Your all contacts with all their selected properties will be imported.
