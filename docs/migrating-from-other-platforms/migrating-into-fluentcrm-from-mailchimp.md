# Migrating into FluentCRM from MailChimp
Migration to FluentCRM is now just a few steps of work.

From your contact dashboard, click **Import**.

![click on import](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailchimp/Click-on-import-1024x492.png)

Then, choose **Import from Other Platforms** and select MailChimp from the list of providers.

![import from other providers](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailchimp/Import-From-Other-Providers-1024x485.png)
![select the preferred crm](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailchimp/Select-the-preferred-CRM-1024x487.png)

On the next screen, you will be asked to give MailChimp API Keys, you can acquire the API key by going to **MailChimp Account**\>**Extras**\>**API keys**

Now Give your API keys and hit Next.

![give api cred mailchimp](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailchimp/Give-API-Cred-Mailchimp-1024x462.png)

Now, simply map all the data(lists, tags, information) you need to import in FluentCRM and click continue.

![map your data mailchimp](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailchimp/Map-Your-Data-Mailchimp-1024x806.png)

Finally, review and Confirm!

![review and confirm](/migrating-from-other-platforms/migrating-into-fluentcrm-from-mailchimp/Review-and-Confirm-1024x253.png)

Your all contacts with all their selected properties will be imported.
